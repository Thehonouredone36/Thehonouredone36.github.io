# Style DNA

The target aesthetic is: **"a sketch someone who does AI, product, and design for years would draw freehand on white paper to explain something."**

## Canvas Specifications

| Property | Spec |
|---|---|
| Format | 16:9 landscape |
| Background | Pure white — no gradients, no texture, no shadow |
| Primary line | Black, hand-drawn, slightly wobbly — not perfectly straight |
| Whitespace | Minimum 35% of canvas empty |
| Subject area | Main subject occupies 40–60% of canvas |

## Color System

Use color sparingly. When in doubt, use less.

| Color | Role | Usage |
|---|---|---|
| Black | Primary — all structural elements, Xiaohei | Always |
| Red | Emphasis — key points, warnings, problems | Sparingly |
| Orange | Flow — arrows, paths, transitions | Sparingly |
| Blue | System info — secondary labels, states | Sparingly |

Rule: **No more than 3 colors total per image.** Prefer 2.

## Annotations

- 5–8 short handwritten-style text labels per image
- Each label: 2–8 words maximum
- Written in a casual, slightly irregular style — not typeset
- Placed near the relevant element, not crowded

## Forbidden Patterns

Never produce work that looks like:

| Forbidden | Why |
|---|---|
| PPT slides or infographic layouts | Too formal, destroys the sketch aesthetic |
| Commercial illustration or stock art | Too polished, wrong register |
| Formal flowcharts with boxes and connectors | Structural diagrams, not conceptual sketches |
| Cartoon posters or mascot art | Wrong character treatment |
| Complex backgrounds or textures | Dilutes whitespace |
| Title text in corner (e.g. "Workflow / 流程图") | Remove — no titles on illustrations |
| Dense explanatory text | Labels only — not paragraphs |
| Gradients, drop shadows, glow effects | No digital polish |

## The Test

Ask: *"Does this look like a bizarre, creative product sketch drawn on white paper, or does it look like a tutorial slide?"*

If it looks like a tutorial slide — it fails.
