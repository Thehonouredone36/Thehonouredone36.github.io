# Xiaohei Character Specifications

## Core Identity

Xiaohei is **"an absurd worker seriously participating in system operations"** — not a mascot, not a cute emoji, not a decoration.

Think: low-key system operator. Cold, serious, slightly bizarre. Dry humor, not cuteness.

## Visual Design

| Trait | Spec |
|---|---|
| Body fill | Solid black |
| Eyes | White circular dots (simple, blank expression) |
| Limbs | Thin, slightly irregular — hand-drawn quality |
| Outline | Slightly wobbly, not perfectly smooth |
| Body shape | Flexible: cylindrical, bean-shaped, box-shaped, etc. — adapts per scene |
| Scale | Typically small-to-medium relative to scene — not overpowering |
| Hat | **Always present**: a small straw hat, hand-drawn, slightly tilted to one side. Consistent across every image. Drawn with the same wobbly line quality as the rest of Xiaohei — not clean or stylized. |

## Personality

- Calm and serious in absurd situations
- Never panicking, never celebrating — just doing the work
- Quiet competence with a hint of "this is fine" energy
- Dry humor through action, not expression

## Role in Illustrations

Xiaohei must **perform the core action** of the conceptual structure. Examples:

| Concept | Xiaohei's action |
|---|---|
| Information filtering | Physically sorting objects through a mechanism |
| Trust building | Laying down blocks or bricks one by one |
| Workflow stages | Moving along a path, operating machinery |
| Bottleneck | Pushing against or stuck at a narrow point |
| Iteration | Repeatedly cycling through a loop |

## The Removal Test

**Ask: if you remove Xiaohei from this image, does the core metaphor collapse?**

- If YES → Xiaohei is correctly integrated
- If NO → Xiaohei is decorative, which is a failure

Xiaohei must be structurally necessary. The moment Xiaohei is optional, the image fails.

## Forbidden Treatments

| Forbidden | Why |
|---|---|
| Cute / kawaii / chibi styling | Wrong register |
| Smiling, winking, or emotional face | Blank expression is core to the character |
| Commercial mascot poses | Not a brand character |
| Standing in the corner watching | Must be active, not observational |
| Replaced by a generic human figure | Xiaohei's abstraction is intentional |
| Given clothes, accessories, or props as costume | Props are tools in use, not decorations — the straw hat is the only permanent exception |
| Straw hat removed or omitted | The hat is a permanent visual signature — always include it |
